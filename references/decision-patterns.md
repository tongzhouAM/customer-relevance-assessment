# 企业类型 → 决策链模式

> 不同企业类型的采购决策路径差异巨大。评估新客户时据此推测决策链和接触策略。

---

## 一、日系跨国集团（在华子公司）

**代表**：先导精密（Ferrotec）、电装、爱信、小系……

**决策链**：
```
工厂设备/生产部门 → 中国区总部技术部 → 日本总部（大额采购）
     ↑ 需求发起           ↑ 技术评估+预算          ↑ 战略审批（>¥500万需）
```

**特征**：
- 需求通常由工厂端发起，但审批在上层
- 决策周期 6-12 月，耐心是关键
- 注重长期合作关系，一旦进入不易被替换
- 技术评估严格，需要详实的试点数据
- 决策人偏保守，倾向选择有行业案例的方案

**接触策略**：
- 从工厂端设备/品质部建立关系（离痛点最近）
- 用免费 Demo 降低决策门槛
- 准备好日文/英文技术资料
- 不要催——日系节奏不可加速

---

## 二、民营制造企业（内资）

**代表**：某汽车内饰Tier1、各类汽车 Tier 1……

**决策链**：
```
品质部/生产部 → 总经理/老板
     ↑ 需求发起+技术评估      ↑ 预算审批（决策快，老板一句话）
```

**特征**：
- 决策快（1-3 月），老板拍板即可
- ROI 是核心驱动力——省多少钱、多久回本
- 喜欢看现场 Demo——"眼见为实"
- 价格敏感但有弹性——如果 ROI 清晰，愿意为好方案多付
- 政府关系可能影响采购（补贴/产业园政策）

**接触策略**：
- 直接找品质总监或老板
- 现场 Demo 胜过十份方案
- 算清楚 ROI（精确到月和金额）
- 利用行业协会/政府关系建立信任

---

## 三、国资/央企

**代表**：中车、航天科工、国机集团……

**决策链**：
```
技术部门 → 采购部门 → 招投标 → 党委会/领导班子
```

**特征**：
- 招投标是必经流程
- 决策周期 6-18 月
- 资质要求高（注册资本/案例/认证）
- 价格不是唯一因素——"政治正确"和合规性同样重要
- 国产替代是加分项

**接触策略**：
- 提前一年介入（在需求形成阶段）
- 通过行业协会/学合作建立信任
- 准备完整的资质材料
- 强调"自主可控""国产替代"叙事

---

## 四、欧美外企（在华工厂）

**代表**：博世、大陆、采埃孚……

**决策链**：
```
中国工厂 → 亚太区总部 → 全球总部（标准化采购）
```

**特征**：
- 全球标准化——一个工厂用上了，容易推广到全球
- 供应商准入门槛高（ISO/TS 认证、EHS 审核）
- 决策周期 3-9 月（比日企快，比民企慢）
- 重视数据安全（数据不出厂是加分项）
- 付款条件好（30-60 天账期）

**接触策略**：
- 从中国工厂切入，证明 ROI 后推亚太/全球
- 准备好英文全套技术文档
- 数据本地化（边缘计算）是卖点
- 强调已有国际客户案例

---

## 五、创业/成长期企业

**代表**：各类 Pre-A 到 B 轮制造业创业公司

**决策链**：
```
CTO/技术负责人 → CEO（决策极快，1-4 周）
```

**特征**：
- 决策快但预算有限
- 技术敏感度高，愿意尝试新方案
- 采购量小（1-2 套起步）
- 可能成为未来大客户，也可能是 dead end
- 付费能力不稳定

**接触策略**：
- 用轻量方案（最小可交付单元，低门槛起步）切入
- 关注其融资/扩产节奏
- 做好"陪跑"准备——与其一起成长
- 控制投入，不做亏本买卖

## 六、被收编整合期的本土体系（混合型）

**代表**：某合资座椅Tier1（重庆）（原宏立至信）、某收购整合型Tier1集团体系、外资收编后的本土 Tier 1……

**决策链**：
```
被收编方总部（本土团队，过渡期握实权） → 外资中国区（新班子） → 全球总部（供应商名单/标准）
```

**特征**：
- 双层文化：本土决策速度 + 全球标准体系接管中——比纯外企摩擦小，比民企流程多
- **整合期 = 标准与供应商名单重构期**：先入 = 写入出生名单，整合完成再进 = 替换在位者
- 实体谱系复杂：合资/兄弟实体决策链独立（如某合资座椅实体 vs 宏立体系），必须分实体评估、并行触达
- 高层换届/总部迁移频发，联系人稳定性差；整合期预算审慎，首单须小额且 ROI 自证

**接触策略**：
- 双线建联（被收编方总部 + 外资中国区），不押注单一联系人，每季度刷新组织地图
- 以「体系统一」叙事上探（多厂一张图/标准一致），用被收编方的本土速度落地首单
- 抢在标准冻结前把方案写入规范；设复评触发器（更名完成/采购归口公告/新定点 SOP）

## 决策链通用速查

| 企业类型 | 决策周期 | 关键决策人 | 核心诉求 | 进入难度 |
|---------|---------|----------|---------|---------|
| 民营制造 | 1-3 月 | 老板/品质总监 | ROI | ⭐⭐ |
| 日系跨国 | 6-12 月 | 中国总部+日本总部 | 长期稳定 | ⭐⭐⭐⭐ |
| 欧美外企 | 3-9 月 | 亚太+全球 | 标准化+安全 | ⭐⭐⭐ |
| 国资/央企 | 6-18 月 | 招投标+领导 | 合规+国产替代 | ⭐⭐⭐⭐⭐ |
| 创业企业 | 1-4 周 | CEO/CTO | 性价比+创新 | ⭐ |
| 被收编整合期本土体系 | 2-6 月 | 被收编方总部（过渡期）+ 外资中国区 | 标准统一+快速落地 | ⭐⭐⭐（窗口期内 ⭐⭐） |

## 情报获取手段菜单（接触路径通用）

| 手段 | 能拿到什么 | 注意 |
|------|-----------|------|
| 行业协会/展会名录 | 组织架构、关键人姓名、新项目风向 | 成本最低，冷启动首选 |
| 招聘平台（JD 信号） | 智能化程度、技术方向、组织扩张点 | 只用于推断不外露；详情页多不被搜索引擎收录，需站内搜 |
| 领英/脉脉 | 质量/工艺/设备口联系人、前员工 | 前员工是「现状痛点」最便宜的情报源 |
| 上下游供应商 | 在位设备商、准入流程、付款信用 | 注意保密与合规边界 |
| 专利/招标监控 | 自研动向、采购窗口（需求单/中标公告） | 招标需求单常直接写明现状痛点（如慈溪座椅全检需求单） |
| 政府/园区公开信息 | 技改补贴、扩建备案、专精特新资质 | 技改补贴可作联合申报杠杆 |
